# rocm-toolkit



Unofficial GitHub Action that installs AMD ROCm (HIP, compilers, libraries) on
Ubuntu/Debian runners, and the HIP SDK on Windows. Supports multiple ROCm
versions and gfx targets, and exports the environment variables you need to
build.
